picforth
========

[![CI](https://github.com/samueltardieu/picforth/actions/workflows/ci.yml/badge.svg)](https://github.com/samueltardieu/picforth/actions/workflows/ci.yml)

Forth compiler for Microchip PIC16Fxxx microcontrollers.

This compiler is tested with gforth 0.7.3 and gforth 1.0.2. Run the test
suite with `make test` (use `make test GFORTH=/path/to/gforth` to select
a specific gforth).
